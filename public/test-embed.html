DropModel Widget Test 🧪

This page simulates an external website embedding the DropModel chat widget. Look for the floating chat button in the bottom-right corner.

How to test

  1. Start the dev server: npm run dev
  2. Create a project in the dashboard and note its Project ID
  3. Replace YOUR_PROJECT_ID in the script tag below
  4. Open this page at http://localhost:3000/test-embed.html
  5. Click the chat bubble and start talking!

Embed snippet

<script src="http://localhost:3000/api/v1/embed/YOUR_PROJECT_ID"></script>
